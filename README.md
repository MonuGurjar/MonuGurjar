# 💻 `./ACERX`

### `Linux Hardware Management Suite`

```text
┌─────────────────────────────────────────────────────────────┐
│                            ACERX                            │
│           Open-Source NitroSense Alternative for Linux      │
│                                                             │
│   ┌──────────────────┐               ┌──────────────────┐   │
│   │ Hardware Drivers │               │   Desktop GUI    │   │
│   │ sysfs / WMI / EC ├──────────────►│ Fan & Power Mode │   │
│   └──────────────────┘               └──────────────────┘   │
│            ▲                                  │             │
│            └──────── Real-time Telemetry ─────┘             │
└─────────────────────────────────────────────────────────────┘
```

**[AcerX-Nitro-Sense](https://github.com/MonuGurjar/AcerX-Nitro-Sense)** is a modern hardware management suite tailored for Acer Nitro V 15 & Predator laptops under Linux.

* **Kernel & EC Control**: Direct communication with Linux hardware interfaces (`sysfs`, `wmi`, embedded controllers).
* **Fan & Thermal Profiles**: Granular custom fan curve adjustments and thermal monitoring.
* **Power & Performance Modes**: Real-time switching between Quiet, Default, Performance, and Turbo modes.
* **Battery Health Preservation**: Configurable 80% charge threshold limiting to protect battery longevity.
* **Modern UI**: Intuitive, high-performance desktop interface built for Linux power users.

> Bridging the gap between proprietary laptop OEM utilities and the Linux ecosystem.
